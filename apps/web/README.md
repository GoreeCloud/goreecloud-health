# GoreeCloud Health Web Foundation

This is a dependency-free responsive development shell. It intentionally contains no health-data backend, account authentication, persistence, analytics, or health-data telemetry.

Run locally:

```bash
python3 -m http.server 4173 -d apps/web
```

Current GLAZE UI V1.3 consumer status is adoption-required/unaccepted; see `../../docs/GLAZE-UI-ADOPTION.md`.
